# University Leaderboard v3 — Public Deployment

This public deployment contains only the application shell and no student names or grades.
Project data is stored locally in the browser or imported/exported by the user.

Files:
- index.html — self-contained web app
- service-worker.js — offline cache
- manifest.webmanifest — installable PWA metadata
- icon.svg — app icon

Do not upload private project backups or student data to a public repository.
